# VibeStudio AI

VibeStudio — это универсальное приложение для генерации текста, картинок, видео и аудио с поддержкой множества моделей на базе Pollinations.ai. Приложение было полностью переведено на английский язык по вашему запросу.

## 🚀 Установка и запуск на компьютере

### Требования
Убедитесь, что у вас установлен **[Node.js](https://nodejs.org/en/download/)** (рекомендуется версия LTS).

### Шаг 1: Скачивание проекта
Склонируйте этот репозиторий или скачайте его архивом (и распакуйте):
```bash
git clone https://github.com/silom2000/pollinations-main.git
cd pollinations-main
```

### Шаг 2: Настройка API ключа
1. В корневой папке проекта найдите файл `.env.example` (если он есть) или создайте новый файл с названием `.env`.
2. Откройте файл `.env` в любом текстовом редакторе.
3. Добавьте ваш API-ключ от Pollinations.ai в следующем формате:
```env
POLLINATIONS_API_KEY=ваш_секретный_ключ
```
*(Получить ключ можно на сайте [enter.pollinations.ai](https://enter.pollinations.ai/))*

### Шаг 3: Запуск приложения
В корневой папке проекта находится файл `Start_App.bat`. 
1. Дважды кликните по файлу **`Start_App.bat`**, чтобы запустить локальный сервер.
2. Консоль запустит сервер на базе Node.js (`server.js`) на порту 3000.
3. Приложение автоматически откроется в вашем браузере по адресу: [http://localhost:3000](http://localhost:3000).

---

## 🛠 Ручной запуск (через консоль)
Если вы не используете `Start_App.bat` (например, на macOS/Linux), вы можете запустить приложение вручную через терминал:
```bash
# Перейдите в корневую папку проекта
cd pollinations-main

# Запустите сервер (дополнительные пакеты устанавливать не нужно, используется встроенный функционал Node.js)
node vibestudio/server.js
```
После успешного запуска перейдите в браузере по ссылке: `http://localhost:3000`.

## ✨ Возможности
* **💬 AI Chat**: Общайтесь с передовыми текстовыми моделями.
* **🖼 Image Generator**: Создавайте изображения высокого качества по текстовому запросу.
* **🎥 Video Generator**: Генерируйте короткие видеоролики на основе текста.
* **🔊 Audio & Music Generator**: Синтезируйте речь или создавайте полноценные музыкальные треки.

Приложение работает через локальный прокси-сервер, который защищает ваш API-ключ и решает проблемы с CORS при обращении к API Pollinations.
